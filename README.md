# Samewave friends-and-family pilot

Listen together in a shared YouTube room. The room host controls playback; listeners join using an invite link. The browser companion is optional.

[Open Samewave](https://samewave-staging.storm-labs.workers.dev) · [Pilot downloads](https://github.com/StormLabsDev/samewave-downloads/releases/tag/v1.0.0-pilot.1)

Use this repository’s Releases page for downloads. Install only assets attached to a release; GitHub’s automatically generated “Source code” archives are not extension packages.

## Choose your browser

- **Chrome:** download [samewave-pilot.zip](https://github.com/StormLabsDev/samewave-downloads/releases/download/v1.0.0-pilot.1/samewave-pilot.zip), extract it into a permanent folder, open `chrome://extensions`, enable Developer mode, choose Load unpacked, and select the `chrome` folder. Keep that folder in place.
- **Firefox 140+:** download [samewave-firefox-1.0.0.xpi](https://github.com/StormLabsDev/samewave-downloads/releases/download/v1.0.0-pilot.1/samewave-firefox-1.0.0.xpi), signed by Mozilla. Open `about:addons`, select the gear menu → Install Add-on From File, and choose the XPI. Approve the installation and required data disclosure. You do not need a developer account.
- **Safari:** open Samewave and paste YouTube links into your room. This is the recommended everyday setup under the pilot’s no-paid-account constraint. The guide includes optional temporary extension testing; it expires after 24 hours or quitting Safari.

After installing the companion, open or join your Samewave room, choose **Connect YouTube**, and approve the connection. Then use the companion from a YouTube song or playlist page.

The ZIP includes an offline `START-HERE.html` guide with installation, connection, updates, troubleshooting, and removal instructions. Extensions use manual updates during this pilot.

Room hosting requires beta access. Your host supplies the listener invite link. No extension or developer account is required simply to join a room through the website.
